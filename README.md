## Project Overview

ANTE Jewellery is a jewellery website created to provide customers with an easy way to view jewellery products and learn more about the brand. The website allows visitors to browse different jewellery products, view product images and prices, learn about custom jewellery options and find contact information.

The website is designed with a simple and modern approach so that customers can easily navigate between the different pages and find the information they need.

## Website Goals and Objectives

The main goals and objectives of the ANTE Jewellery website are:

- To showcase the jewellery products offered by ANTE Jewellery.
- To provide customers with clear product information and prices.
- To display high-quality product images.
- To provide information about custom jewellery.
- To make it easy for customers to contact the business.
- To provide access to the ANTE Jewellery Instagram page.
- To create a simple and easy-to-use website.
- To provide clear navigation between all website pages.

## Target Audience

The target audience for ANTE Jewellery includes customers who are interested in jewellery for everyday wear, gifts and special occasions. The website is aimed at customers who want to browse jewellery products online and learn more about the available products and services.

## Key Features and Functionality

The website includes the following features:

- Home page introducing ANTE Jewellery.
- About Us page containing business information, mission and vision.
- Products page displaying jewellery products, descriptions and prices.
- Custom Jewellery page providing information and an enquiry form.
- Gallery page displaying jewellery product images.
- Shopping Cart page for selected products.
- Contact Us page containing contact information and a contact form.
- Navigation menu connecting the different website pages.
- Product images and descriptions.
- Instagram link for the ANTE Jewellery social media page.
- Basic HTML forms for customer enquiries and contact information.

## Part 2 - CSS Styling and Responsive Design

Part 2 focused on improving the visual appearance and responsiveness of the ANTE Jewellery website. An external CSS stylesheet was created and linked to all website pages.

### CSS Styling

The website was styled using an external style.css file. The styling includes:

- Consistent colours and fonts
- Typography and spacing
- Navigation styling
- Product cards
- Buttons and forms
- Borders and shadows
- Hover effects
- Image effects
- Responsive layouts

### Responsive Design

The website was designed to work on desktop, tablet and mobile screen sizes.

Desktop uses a three-column layout for products and gallery items. Tablet uses a two-column layout, while mobile uses a single-column layout.

Media queries were used to adjust the layout, navigation, font sizes and images for different screen sizes.

# ANTE JEWELLERY – PART 3
## Enhancing Functionality and SEO

### 1. Introduction

This README documents the development and improvements made to the ANTE Jewellery website for Part 3 of the WEBE5020 Web Development Introduction Portfolio of Evidence.

The purpose of Part 3 was to improve the functionality of the existing website by introducing JavaScript features, improving customer interaction, developing forms and applying Search Engine Optimisation (SEO) techniques.

ANTE Jewellery is an online jewellery store that allows customers to browse jewellery products, view collections, make product enquiries and contact the business.

The website was developed using HTML5, CSS3 and JavaScript.

### 2. Part 3 Objectives

The main objectives of Part 3 were:

- Improve the website using feedback received from Part 2.
- Add interactive features using JavaScript.
- Improve website functionality and user experience.
- Create product enquiry and general contact forms.
- Apply HTML5 and JavaScript form validation.
- Improve the website's SEO.
- Improve navigation and internal linking.
- Make the website suitable for mobile devices.
- Prepare the website for deployment using a free hosting platform.
- Document development changes using GitHub and the README changelog.

**HTML5:** Used to structure website pages, product information, images, navigation and forms.

**Contact Form – contact.html**

The form collects:

- Customer name.
- Email address.
- Message type.
- Full message.

### 7. Form Validation

HTML5 and JavaScript validation are intended to help ensure that customers enter the required information correctly before submitting forms.

Validation can check required fields, email formats, telephone numbers and message lengths.

### 8. Search Engine Optimisation (SEO)

SEO improvements were considered during development to help search engines understand the website and its content.

The SEO techniques include:

- Unique page titles for individual website pages.
- Meta descriptions explaining the content of each page.
- Relevant headings to organise website content.
- Descriptive image filenames.
- Alternative text for images using the HTML alt attribute.
- Internal links connecting the website pages.
- Responsive design to support mobile users.
- A sitemap.xml file to help search engines discover website pages.
- A robots.txt file to provide crawling instructions to search engines.

### 9. Online Business and Local SEO

ANTE Jewellery operates as an online-only jewellery store and does not currently have a physical retail location.

For this reason, a physical business address and location-based business listing are not applicable.

The SEO strategy focuses on online visibility through relevant jewellery keywords, product descriptions, page titles, meta descriptions and social media promotion.
